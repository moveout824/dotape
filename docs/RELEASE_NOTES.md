# DOTAPE 0.1.0

Rust 네이티브 도트 녹음기·오디오 편집기입니다.

- 갈무리 내장, 픽셀 아이콘, 낮은 대비의 설정 패널
- 입력 장치 선택과 실시간 파형 녹음
- 무제한 트랙, 마우스 다중 선택·이동, 빈 트랙 자동 정리
- 빈 공간 드래그로 선택과 재생선 이동을 함께 수행
- 화면 밖 재생선 드래그와 가로·세로 이동, 마우스 기준 휠 확대
- 클립 볼륨 선, 페이드 음영, 서로 밀어내는 페이드 손잡이
- 원본 범위 내 트림, 잘린 면의 직각 표시, 원본 연속 구간 이어붙이기
- 클립 정렬 자석과 빨간 가이드, N키 토글
- WAV / MP3 / FLAC / OGG, 병합 또는 트랙별 출력

Windows x64용 ZIP을 풀고 `DOTAPE.exe`를 실행하세요. 녹음과 개인 작업 데이터는 배포 파일에 포함하지 않습니다.

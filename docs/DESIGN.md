# 작은 도트 녹음기

DOTAPE는 소리를 편집하는 동안 도구가 앞에 나서지 않게 만든다.

- **요소를 겸용한다.** 시간 표시는 재생 위치와 녹음 시간을 함께 맡는다. 입력 선택 아래 막대는 입력 상태를 보여준다. 내보내기 버튼에는 현재 형식을 표시하고, 오른쪽 클릭으로 저장 위치를 연다.
- **직접 만진다.** 빈 공간을 드래그하면 클립 선택과 재생선 이동이 함께 일어난다. 클립 중앙 선은 볼륨, 위쪽 손잡이는 페이드, 아래쪽 끝은 원본 범위의 길이 편집이다.
- **말보다 상태를 보여준다.** 선택한 클립은 밝게, 음소거는 붉게, 붙잡힌 정렬 위치는 빨간 선으로 표시한다. 트랙 구분은 선 대신 명암을 번갈아 쓴다.
- **필요할 때 설명한다.** 평상시에는 짧은 값만 두고, 마우스를 1.5초 멈췄을 때 고르는 방법을 보여준다.

먹색 바탕, 크림색 글자, 살구색 강조색을 기본으로 쓴다. 갈무리는 12px와 정수 배율을 중심으로 사용한다. 아이콘은 작은 비트맵 패턴을 Rust 사각형으로 그린다. 외부 이미지 로딩이나 웹뷰는 사용하지 않는다.

설정 패널은 본 화면보다 두드러지지 않도록 같은 바탕색과 낮은 대비의 경계를 사용한다. 값의 가독성은 유지한다. 원본 클립의 양끝은 계단형 모서리, 잘라낸 면은 직각으로 구분한다. 트랙 배경은 밝은 먹색과 어두운 먹색을 번갈아 사용한다.
